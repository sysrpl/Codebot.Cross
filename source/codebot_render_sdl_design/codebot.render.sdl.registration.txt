The Codebot.Render.Sdl.Registration unit adds the Codebot rendering project to the new project dialog of the Lazarus IDE. Choose File, New, and then Codebot rendering project to create a program that runs a scene in an SDL window.

Your new project is made of two files. The program sets the title of the application and runs your scene. The MainScene unit holds TMainScene, a scene for you to change into your own, which draws a rose on the canvas that turns, opens and closes its petals, and changes color over time. It needs no assets, so it runs as soon as you build it. The project requires the codebot, codebot_render, and codebot_render_sdl packages, and has no forms.

Before the project is created, you are asked whether your assets should be encrypted with a key. If you choose a key, a random key of four bytes is made up and your program sets it with Application.AssetKey. Your program then reads its assets from a dat file beside it, and builds that file when you start it with `--build-dat`. Your choice is also kept in the project file under the name in BuildDatName, so a release build on macOS knows whether to place the dat file or the assets folder inside the application bundle.
