The Codebot.Render.Shaders unit compiles and links OpenGL shaders. TVertexShader and TFragmentShader compile a shader from source code, and TShaderProgram links the two together into a program used for drawing. Source code without a #version directive is given one that matches the OpenGL version chosen in render.inc. Ctx.Shaders holds shader programs by name, loading name.vert and name.frag from the shaders folder of the assets.
