The Codebot.Render.Widgets unit gives you a user interface drawn on a canvas inside a scene, with no help from the LCL or the system. TWidget is the base class of every widget, and TMainWidget is the parent of a layout and also shows message boxes. You add widgets to a parent with Add, such as `Window.Add<TPushButton>`, and freeing a widget frees its children.

| Widgets | Description |
| --- | --- |
| TLabel, TEdit, TMemo | Text you show, and text the user types. |
| TPushButton, TGlyphButton, TCheckBox | Buttons and check boxes. |
| TSlider, TSpinBox | Pick a number. |
| TListBox, TScrollGrid | Lists and grids that scroll. |
| TGlyphImage, TPaintBox, TSpacer | Images, your own drawing, and empty space. |
| THBox, TVBox | Arrange their children in a row or a column. |
| TScrollBox | Holds other widgets in an area that scrolls. |
| TWindow | A container with a title bar, which stacks the widgets you add and sizes itself to fit them. The user can drag, close, and resize it, and you can show it as a modal window. |
| TCustomWidget | The base class of widgets that draw themselves. |

TTheme is the base class of the themes that draw the widgets and give the sizes of their parts. The themes themselves are in Codebot.Render.Widgets.Themes.
