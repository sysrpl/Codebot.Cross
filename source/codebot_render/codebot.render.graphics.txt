# Codebot.Render.Graphics

The Codebot.Render.Graphics unit gives you ICanvas, which draws smooth antialiased 2D vector graphics with OpenGL using Codebot.Render.NanoVG. You build up a path with MoveTo, LineTo, Rect, RoundRect, Circle, Ellipse, and the other path methods, and then Fill or Stroke it with a color, a pen, or a brush. The canvas also draws images, sprites, and text, and its matrix lets you rotate, scale, and move what you draw. Drawing happens between two calls to Flip on the canvas's IBackBuffer.

| Interface | Description |
| --- | --- |
| IPen | Strokes paths. |
| ISolidBrush, ILinearGradientBrush, IRadialGradientBrush, IBoxGradientBrush, IBitmapBrush | Fill paths with a color, a gradient, or an image. |
| IFont | Describes how text is drawn. |
| IBitmap | An image. IRenderBitmap is an image you can draw into. |
| ISprite | Draws one cell of a sprite sheet. |
| ITextWriter | Writes formatted text over several lines. |
| IMatrix | A 2D transform. |

NewCanvas, NewPen, NewBrush, NewSprite, NewMatrix, NewColorF, NewHSL, and the other New routines create them. A canvas must be created and used while an OpenGL context is current, which the scene hosts take care of for you.
