The Codebot.Interop.MinGW unit links, on Windows, the static libraries built with MinGW-w64, which are libchipmunk2d.a and libcodebotaudio.a, followed by the C runtime they use. The Free Pascal linker searches each static library once, in the order it first meets them, so every library using the C runtime must come before it. Where the libraries of a unit are placed depends on the order the units are loaded, so this unit links all of them itself, ahead of the C runtime, and each unit linking one of them uses this unit in its implementation section. A library which is linked but not called adds nothing to the program. A MinGW-w64 library added later is linked here as well. On other systems the unit links nothing.
