# Codebot.Interop.MinGW

The Codebot.Interop.MinGW unit makes the static libraries built with MinGW-w64, libchipmunk2d.a and libcodebotaudio.a, link correctly on Windows. The Free Pascal linker searches each static library once, in the order it first meets them, so every library using the C runtime must come before it. Since that order depends on the order units are loaded, this unit links all of them itself, ahead of the C runtime, and each unit linking one of them uses this unit. A library that is linked but never called adds nothing to your program. On other systems the unit links nothing.
