The Codebot.Render.NanoVG unit is a Pascal port of NanoVG by Mikko Mononen, which is an antialiased 2D vector drawing library rendered using OpenGL. The port includes the OpenGL backend, which works with every OpenGL version that can be chosen in render.inc. Text is drawn using Codebot.Render.FontStash, and images are loaded using NewBitmapData from Codebot.Platform. The canvas in Codebot.Render.Graphics is built on top of this unit.
