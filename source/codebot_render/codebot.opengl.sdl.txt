The Codebot.OpenGL.SDL unit provides the platform routines of Codebot.OpenGL using SDL2, so they work the same way everywhere SDL does. Every OpenGL context is created by this unit, both for the window of an SDL application and for the SDL window that a TGraphicsBox places inside an LCL form. OpenGLSetAttributes sets the SDL attributes for the OpenGL version chosen in render.inc, and it must be called before the window is created.
