# Codebot.Collections

The Codebot.Collections unit gives you generic collections for when a TArrayList is not enough.

| Class | Description |
| --- | --- |
| TList<TItem> | A list that grows as you add items. |
| TIndexedList<TItem> | A list where you can find and remove items by value. |
| TObjectList<TItem> | A list of objects that can free them for you. |
| TDictionary<K, V> | Key and value pairs indexed by key. |
| IList<T> | A reference counted list, implemented by TObjects<T>, which can free its objects when they are removed, and TInterfaces<T>, which holds a reference to each interface. |
| TAggregateStream | Reads a series of text, files, and streams as if they were one continuous stream. |
