The Codebot.Binding unit lets you link components so that a change in one of them is passed on to the others. TComponentBinding holds the bound components by name, so they are saved with your form, and they must have the same owner as the binding.

To write a binding, descend from TComponentBinding, choose which classes can be bound with AcceptClass, and decide what a change does by overriding DoChange. A bound component calls Change on its IComponentBinding to pass a change on, and components that implement IComponentBindingClient are given a reference to the binding they belong to. Changes made while the binding is already passing one on are ignored, so bound components can update each other without looping.

TExplorerBinding in the codebot_windows_shell package is built this way.
