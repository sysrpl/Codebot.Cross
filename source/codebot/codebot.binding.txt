The Codebot.Binding unit links components so that a change in one of them is passed on to the others. TComponentBinding holds the bound components by name, so they are saved with a form, and they must have the same owner as the binding. Descendants choose which classes can be bound with AcceptClass and decide what a change does by overriding DoChange. A bound component calls Change on its IComponentBinding to pass a change on, and components which implement IComponentBindingClient are given a reference to the binding they belong to. The binding ignores changes made while it is already passing one on, so bound components can update each other without looping.
