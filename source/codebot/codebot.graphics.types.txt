The Codebot.Graphics.Types unit describes 2D drawing without depending on any particular way of doing it. It gives you colors, points, rectangles, and matrices, with routines to blend, lighten, darken, fade, and convert colors and to look up colors by name, along with the drawing interfaces:

| Interface | Description |
| --- | --- |
| ISurface | Draws paths, shapes, text, and bitmaps. |
| IPen | Strokes paths. |
| IBrush | Fills paths. ISolidBrush fills with a color, IBitmapBrush with a repeating bitmap, and ILinearGradientBrush and IRadialGradientBrush with blended colors. |
| IFont | Describes how text is drawn. |
| IPath | The path built by a surface's drawing commands. |
| IMatrix | A 2D transform used by surfaces and brushes. |
| IBitmap | An image you can load, save, and draw on. |
| ISplash | A floating window whose shape is defined by a bitmap. |

These interfaces are implemented by Codebot.Graphics in the codebot_controls package, using Cairo, Direct2D, or Quartz.
