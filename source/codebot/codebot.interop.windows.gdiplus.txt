The Codebot.Interop.Windows.GdiPlus unit declares the GDI+ API on Windows and wraps it in interfaces for graphics, pens, brushes, paths, regions, images, bitmaps, fonts, and string formats. It also defines TFastBitmap, which is a bitmap whose pixels can be accessed directly, along with routines that draw and blend it onto a device context. This unit is used by the GDI+ drawing surface in the codebot_controls package.
