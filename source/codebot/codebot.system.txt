# Codebot.System

The Codebot.System unit holds the types and routines the rest of the library is written in, and you will use it in nearly every unit you write. List it first in the uses clause of your program, in place of the cthreads block Lazarus generates, so threads are ready before any other unit starts.

It gives you:

- Float, the floating point type used everywhere in the library, along with the other basic types.
- TArrayList<T>, which extends dynamic arrays so they can push and pop, sort, search, filter, reverse, and join their items. StringArray, IntArray, Int64Array, and FloatArray already know how to sort and join their items. TStack<T> is a fixed size stack.
- Routines for math, time, strings, and files, including ConfigAppDir and ConfigAppFile, which find where your program should keep its settings.
- Helpers that add methods to strings, integers, dates, and TStrings, so you can write things like `S.Trim.ToUpper` or `S.Split(',')`.
- Named values and named strings, which are simple dictionaries keyed by name.
- Delegates, which let an event have any number of subscribers, and TChangeNotifier, which tells owners when something changes.
- TNullStream, which counts the bytes written to it without storing them.
- Threading support, including IMutex, IEvent, TSimpleThread, which runs a method on its own thread, and IAsyncTask, which lets you run cancellable work in the background and follow its progress.

When an interop unit can't load a library or one of its routines, Codebot.System raises an ELibraryException that tells you which one.
