The Codebot.Text.Xml unit provides XML documents through a set of interfaces. IDocument is the root of an XML tree, INode is an element, attribute, text, or document node, and INodeList is a list of attributes or child nodes. IFiler reads and writes typed values to nodes selected by an XPath key, and can optionally encrypt them. SettingsLoad and SettingsSave read and write the settings file of the application.

On Linux the implementation uses libxml2, and on Windows it uses MSXML.
