The Codebot.Platform.SDL unit provides the Codebot.Platform interfaces using SDL2. Bitmaps are TBitmapDataSDL objects, which are loaded and saved using SDL_image, the clipboard is the SDL clipboard, and message dialogs are SDL message boxes. Since SDL has no file dialogs of its own, the file and picture dialogs are built from widgets instead. The platform routines are assigned when this unit is initialized.
