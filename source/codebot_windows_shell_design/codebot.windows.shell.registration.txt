The Codebot.Windows.Shell.Registration unit registers TExplorerTree, TExplorerView, TExplorerEdit, TExplorerPreview, TExplorerBinding, TShellFileOperation, TShellNotify, and TShellLink with the Lazarus IDE, placing them on the Windows Shell page of the component palette. It also registers TExplorerPathPropertyEditor for the Path of TExplorerView, TExplorerEdit, and TShellNotify and the Root of TExplorerTree, a file name editor for the FileName of TShellLink, and TExplorerBindingEditor as the component editor of TExplorerBinding.
