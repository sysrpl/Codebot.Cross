The Codebot.Windows.Explorer.Editors unit defines TExplorerPathPropertyEditor, the property editor of the Path of a TExplorerView, TExplorerEdit, or TShellNotify and the Root of a TExplorerTree. Its drop down list holds common shell places such as This PC and Network, which are stored by their shell parsing names, and special folders such as Documents and Downloads, which are stored by their known folder names such as shell:Downloads so they work for any user. Desktop is stored as the empty path. The ellipsis button opens the Windows folder picker, which can also pick virtual folders. Text which does not name a folder is rejected and the previous value is kept.
