The Codebot.Design.AppExplorer unit defines the Application Explorer, which is a form that shows a tree of every component owned by the Application variable. It can be used to browse the components of the Lazarus IDE or of a running program. When a component is destroyed its node is removed from the tree, so a node never refers to a component that no longer exists. The Application Explorer can be opened from the menu of the IDE, and a program can show it by calling ShowAppExplorer.
