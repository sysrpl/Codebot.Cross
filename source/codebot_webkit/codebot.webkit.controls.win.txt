The Codebot.WebKit.Controls.Win unit defines the Win32 widgetset classes of the browser and inspector controls, using Microsoft Edge WebView2. TWSWebBrowser creates the web view in the background after the window of the control and carries out the requests of the control, keeping any made before the web view is ready. The events of the web view reach the controls through IWebBrowserEvents, using the same values as WebKitGTK. WebView2 can only show its developer tools in a window of their own, so TWSWebInspector has a web view of its own showing the developer tools page of the WebView2 debugging server, which listens only on the local computer. The server is started only when an inspector control is created before the first web view, and without it the developer tools open in a window of their own. A control has no web view at design time, or when WebView2Loader.dll or the WebView2 runtime is missing.
