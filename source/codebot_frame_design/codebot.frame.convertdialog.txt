The Codebot.Frame.ConvertDialog unit defines the dialog shown before a form or frame is converted into a control. It asks for the class name of the new control, the name of its unit, and the page of the component palette it is registered on. It also asks whether the unit is added to a new package or to an existing one. A new package is chosen with a save dialog, and the name of the package is the name of its file. The name of the unit is made from the class name, so that TMyCrazyGrid is placed in the unit MyCrazyGridCtrls. The unit is written to the folder of the package, in a file named after the unit in lowercase, such as mycrazygridctrls.pas. If the unit already exists, because a changed form or frame is being converted again, the dialog asks before it is replaced. The dialog also asks whether the package is installed in the IDE once the control is created, and whether the new unit is opened in the source editor.

ShowConvertDialog shows the dialog and returns the choices in a TConvertOptions record.
