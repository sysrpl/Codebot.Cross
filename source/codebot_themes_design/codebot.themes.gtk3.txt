The Codebot.Themes.Gtk3 unit themes every window of the program with the GTK3 widgetset by adding one style sheet to the screen. It is used with the GTK3 widgetset only. GTK styles every widget again when the style sheet changes, including the widgets created later, so nothing is patched and nothing is hooked.

Gtk3ThemesInstall adds an empty style sheet to the screen, and returns false if the widgetset is not GTK3. Before that it saves the system colors the widgetset reads from the theme of GTK, and puts them in SystemColors, so that the dialog shows the theme System Default as it really is. The style sheet has a priority above the theme of GTK and below the style sheets the widgetset gives single widgets, so that a control with a color or a font of its own keeps it.

Gtk3ThemesSetTheme fills the style sheet from a theme of Codebot.Themes.Palettes. Each color of the palette is defined with @define-color as cb_ followed by its name in ColorNames, along with the colors the widgetset looks up by name, such as theme_bg_color, theme_base_color, and theme_selected_bg_color. The rules which follow give windows, menus, tool tips, buttons, check boxes, edits, lists, tabs, scroll bars, and the other widgets the colors of the palette, and the font of the theme. A dark theme also turns on gtk-application-prefer-dark-theme, so that GTK starts from its dark theme and the title bars are dark where the window manager allows. The theme System Default empties the style sheet.

The widgetset reads the system colors the LCL paints with from the style sheet when it is told the name of the GTK theme changed, which the unit tells it without changing the name. Afterwards a callback of the unit sets the system colors to the colors of the palette, as the widgetset reads several of them from one color, gives the cached brushes and the pens the LCL keeps for reuse the colors again, as the widgetset turned the system color of a pen into a fixed color when the pen was made, and sets the color of every control whose color is a system color again, as the widgetset turned it into a fixed color when it was set.

Gtk3ThemesUninstall removes the style sheet, puts back the dark setting and the system colors as they were, and removes the callback if it has not run, so that nothing calls into the unit again.
