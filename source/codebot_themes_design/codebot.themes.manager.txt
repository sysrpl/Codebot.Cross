# Codebot.Themes.Manager

The Codebot.Themes.Manager unit applies the themes of Codebot.Themes.Palettes to the IDE, and remembers the theme you chose between sessions of the IDE.

ThemesStart loads the themes, installs what they need, and applies the theme saved in codebotthemes.xml in the configuration folder of the IDE, or the Dark theme if none was saved. It returns False if themes can't be used on your system, which is when the widgetset is neither the Windows widgetset nor the GTK3 widgetset. ThemesApply applies a theme while the IDE runs, including its colors, its menu font, and the font of every form of the IDE, even forms created later. ThemesSave saves the name of the theme in use, and ThemesCurrent returns its index in ThemeList. ThemesStop takes the theme away and everything ThemesStart installed, and gives the forms back the font of the system, so the IDE is left as it was.

The themes are loaded from two folders. The themes folder beside the package holds the themes that come with it, and the codebotthemes folder in the configuration folder of the IDE holds your own. If one of your themes has the same name as one of the package's themes, yours replaces it, so you can change a theme without changing the package.
