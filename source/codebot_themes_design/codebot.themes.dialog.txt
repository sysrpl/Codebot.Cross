# Codebot.Themes.Dialog

The Codebot.Themes.Dialog unit gives you the dialog that chooses the theme of the IDE and the color scheme and font of the source editor, on two tabs.

The Theme tab lists the themes. Beside the list, a preview draws a window of the IDE in the colors and font of the selected theme, with a title bar, a menu bar, tabs, a list, an edit, buttons, a check box, and a status bar.

The Editor tab lists the color schemes of the source editor, with a font and a font size above them. Only fonts whose characters all have the same width are listed. Beside the list, a preview draws Pascal source with line numbers in the colors of the selected scheme and the chosen font, with its comments, directives, strings, numbers, and reserved words each in their own colors. The tab is hidden when the IDE has no color schemes.

You can double click a theme or a scheme to choose it, and the Apply button applies your choices so far while leaving the dialog open. TThemeChoice holds what the dialog chooses, and ShowThemesDialog shows the dialog and returns True along with the choice made if you pressed OK. The Apply button calls the TThemeApplyProc you give to ShowThemesDialog.
