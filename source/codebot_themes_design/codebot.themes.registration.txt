The Codebot.Themes.Registration unit registers the codebot_themes_design package with the Lazarus IDE. When the package is registered, the windows of the IDE exist already, so it starts the themes of Codebot.Themes.Manager, which applies the saved theme to every window. It then adds a Themes item to the Tools menu, which shows the dialog of Codebot.Themes.Dialog, applies and saves the theme chosen, and applies the color scheme of the source editor chosen with Codebot.Themes.Editor when it changed. Nothing is added when themes can not be used on the system.

An IDE built from dynamic packages can unload a package while it runs, so the unit adds a handler with AddModuleUnloadHandler. Before the library of this package is unloaded, the handler takes the theme away and everything that was installed, as nothing may call into the library once it is gone. The IDE removes the menu item itself. Before another library is unloaded, the handler forgets the slots patched in it.
