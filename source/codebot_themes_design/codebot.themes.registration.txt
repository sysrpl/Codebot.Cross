The Codebot.Themes.Registration unit starts the themes when the Lazarus IDE loads the package. It loads the themes with ThemesReload of Codebot.Themes.Install, from the themes folder of the codebot_themes package and from the codebotthemes folder in the configuration folder of the IDE, where your own themes go. By then the windows of the IDE already exist, so it applies your saved theme to every one of them right away. It then adds a Themes item to the Tools menu, which shows the dialog of Codebot.Themes.Dialog, applies the theme you choose and saves its name to codebotthemes.xml in the configuration folder of the IDE, and applies the color scheme and font of the source editor you choose when they change. The menu item isn't added when themes can't be used on your system.

The unit also adds TThemeManager to the Codebot Themes tab of the component palette. Double clicking the component, or clicking the button of its Theme or Themes property, shows the dialog of Codebot.Themes.Picker. The Theme property also drops down a list of every theme the IDE has, and choosing one stores it in the form. The Themes property shows the names of the themes stored in the form.

An IDE built from dynamic packages can unload a package while it runs, so the unit adds a handler that takes the theme away, along with everything that was installed, before the package is unloaded, since nothing may call into it once it is gone. Before any other library is unloaded, the handler forgets the routines that were patched in it.
