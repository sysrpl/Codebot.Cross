# Codebot.Windows.Explorer

The Codebot.Windows.Explorer unit gives you controls that host the parts of Windows Explorer itself. They show the same folders, icons, columns, context menus, and previews as Windows Explorer, and they work with any shell folder, including virtual folders such as This PC, Control Panel, and the Recycle Bin.

| Control | Description |
| --- | --- |
| TExplorerView | Shows the items of a folder using the explorer browser, with the view modes, columns, sorting, grouping, filtering, and search of Windows Explorer. It keeps a history for GoBack and GoForward, and can copy, paste, rename, and delete the selected items. |
| TExplorerTree | Shows the folder tree of the navigation pane, optionally with checkboxes. |
| TExplorerEdit | Shows the path of a folder as an edit with autocomplete, as a breadcrumb with a menu of subfolders for each folder, or as an edit with a drop down tree. |
| TExplorerPreview | Shows a file using the preview handlers of Windows. For files without one, it shows their thumbnail and details such as their size, version, dimensions, or duration. |
| TExplorerBinding | Keeps views, trees, edits, and previews in sync. When one of them moves to a folder the others follow, and previews show the item selected in a view. |

You can give any of these controls a file system path, a shell parsing name such as `::{20D04FE0-3AEA-1069-A2D8-08002B30309D}` for This PC, or a known folder such as `shell:Downloads`. The empty path is the desktop. A path is kept as you give it, so a view set to `shell:Downloads` reports `shell:Downloads` while it shows that folder. If you need item ID lists, ShellPathToIDList and ShellIDListToPath convert paths to them and back.

The windows Windows creates inside these controls pass their mouse and keyboard input on to the control, so the usual events such as OnMouseDown, OnKeyDown, OnContextPopup, and OnDragOver work just as you would expect. At design time those windows let the mouse pass through, so you can select the controls in the form designer.

The unit is for Windows only.
