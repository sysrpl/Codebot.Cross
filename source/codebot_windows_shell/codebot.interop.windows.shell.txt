# Codebot.Interop.Windows.Shell

The Codebot.Interop.Windows.Shell unit declares the parts of the Windows shell API that the Free Pascal ShlObj unit is missing, or declares in a form you can't use. It covers the explorer browser and the namespace tree control with their events, IFolderView2 and IColumnManager for the folder view, autocomplete, item images, preview handlers, search folders and conditions, file operations, known folders, change notifications, and the property system.

Interfaces are only declared up to the last method the explorer units use, so you won't find the later methods of an interface here. Parameters that take objects the explorer units never create, such as progress sinks, are declared as IUnknown and passed as nil.

The unit is for Windows only.
