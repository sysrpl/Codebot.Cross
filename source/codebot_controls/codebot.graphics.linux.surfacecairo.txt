# Codebot.Graphics.Linux.SurfaceCairo

The Codebot.Graphics.Linux.SurfaceCairo unit is the drawing backend of Codebot.Graphics on Linux. It implements matrices, pens, brushes, fonts, surfaces, bitmaps, and splash windows using Cairo, and captures the screen using GTK. You don't use it directly. Codebot.Graphics calls it for you.
