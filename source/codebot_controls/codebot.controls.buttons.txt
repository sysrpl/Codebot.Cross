The Codebot.Controls.Buttons unit gives you TThinButton, a flat button that draws itself using the current theme and can show an image from an image strip. Its Kind decides how it behaves:

| Kind | Description |
| --- | --- |
| bkButton | A plain button. |
| bkDropDown | A button with a second area for a drop down arrow. |
| bkDialog | A button with a second area for an ellipsis. |
| bkSpin | A button with up and down areas. |
| bkSplitter | A splitter. |
